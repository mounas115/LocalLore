# LocalLore – Tourism Guide and Local Guide Booking

## Project Overview

LocalLore is a web-based tourism platform designed to help tourists discover local attractions, explore guided tours and book reliable local guides.

The application also provides AI-powered itinerary suggestions based on attractions and timings available in the system.

## Objectives

- Help tourists discover local attractions and experiences.
- Allow local guides to create and manage profiles.
- Enable tourists to book guides based on availability and group size.
- Generate AI-based itineraries using verified listed attractions.
- Apply software engineering practices throughout development.

## Technology Stack

- Frontend: React
- Backend: Python Django REST Framework
- Database: PostgreSQL
- AI Integration: Gemini API
- Version Control: Git and GitHub
- DevOps: Docker, Jenkins and GitHub Actions
- Testing: pytest, Selenium and Postman
- Monitoring: Prometheus and Grafana

## Project Structure

- backend – Django backend application
- frontend – React frontend application
- docs – Project documentation
